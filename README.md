# SmartBooks — Online Bookstore (system design)

A team project for the **Software Design & Architecture** course at the German International University (Winter 2025).

SmartBooks is a design for an online bookstore. Customers create accounts, search and browse a catalogue, add books to a cart, pay online, and track their orders, while admins manage stock and suppliers. The work here is the design itself — the requirements, the diagrams, and the architecture — not a running application.

## What's inside

All three deliverables are in `deliverables/`:

1. **Expert interview** — the requirements, gathered as a question-and-answer interview with the "client".
2. **UML sequence & BPMN diagrams** — the main workflows of the system (registration, search, cart, checkout, order tracking) drawn as sequence and business-process diagrams.
3. **Architecture model** — the chosen design: a **microservices** backend (so busy parts like search can scale on their own) and a **Progressive Web App** frontend (one app that works on web and mobile), with the reasons for each choice.
